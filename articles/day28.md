## 正文施工單

### 1. 固定待驗證版本與讀者起點

記錄實際 commit、作業系統與最低必要背景。清楚列出自備帳號、測試頻道、秘密與可能費用；不能把作者的私有設定當成讀者理所當然具備。

### 2. 從乾淨環境照文件逐步执行

使用新容器、虛擬環境或獨立機器，依真實狀況描述隔離程度。不得偷偷使用舊依賴、環境變數或快取；遇到缺步驟先記下再修文件。

### 3. 把離線、模型、LINE 與雲端驗證分級

讓不提供憑證的讀者仍能檢查合成規格與確定性測試；真實 API 与部署另列明確入口。每個階段都有預期輸出、常見錯誤與清理／停止方法。

### 4. 清楚交代可重用範圍與限制

依作者已正式確認的授權檔說明程式、文章、圖片、Logo 與資料範圍；尚未決定就列缺口，不擅自補授權。README 的功能狀態與實測成果也要同步，不把計畫保留成已完成描述。
