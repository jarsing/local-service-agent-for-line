# Day 2｜從驗收規格到可執行實驗

程式：[examples/day02](../../examples/day02/README.md)。原始規格：[Day 1 JSON](../day01/handoff-timeout-001.json)。

本篇要驗證的是：寫入工具逾時、結果未知時，先保持待核對；沿用原操作識別查回結果；相同操作不產生第二筆。

| 觀察 | 不能誤推論成 |
|---|---|
| 工具逾時 | 後端一定失敗，或一定完成 |
| 請求已建立 | 真人已接受，或服務已完成 |
| 同鍵再次送出 | 可以改內容，或換新識別重建 |

此範例保存真實本機 SQLite 紀錄，故障為合成注入；不含 Gemini／LINE／雲端呼叫。使用者身分、操作確認與正式服務流程留待後續完成。

重現時保留 Python／SQLite、命令、退出碼與程式版本。`verify.py` 可以產生可直接開啟的本機 HTML 報告；它不是假終端截圖，也不代表全平台測試成功。

本檔刻意不預填作者的測試日期、已發布文章網址、正式部署或模型成效。欲公開實測摘要，請先核對自己的真實紀錄與去識別範圍。
