# Day 4 重現入口

[程式與步驟](../../examples/day04/README.md)將 Day 3 固定合成案例接到 LINE 測試頻道。先驗簽，再限定使用者與指令；HTTP 收件、模型文字、Reply API 與手機顯示分開核對。

執行方式：先做離線驗證，再由作者核准本機服務、HTTPS 開發入口與測試頻道操作。原始實驗紀錄保存在 Repo 外，參照 `examples/day04/README.md`。

本目錄不預先宣稱作者已完成真實 LINE／Gemini 整合。離線替身、真實服務回應與作者手機截圖，分別提供不同證據；文章應依當次實測填寫，不從測試數推論模型或整套 Agent 可靠。

程式使用單一行程內的記憶體佇列與去重，沒有持久化工作恢復、業務建單、ADK 或雲端部署。範例適用開發測試，不是可直接投入正式營運的服務。
